Từ khóa phong cách: chân dung dark academia, chụp ảnh thời trang cao cấp (high-fashion editorial), ánh sáng low-key, độ sâu trường ảnh nông, hiệu ứng ống kính 85mm, kiệt tác, 8k, độ chi tiết cao.
